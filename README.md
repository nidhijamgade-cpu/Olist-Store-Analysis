Olist Store Analysis
📌 Project Overview
This project analyzes e-commerce data from the Olist Store to understand customer behavior, payment patterns, delivery performance, product performance, and the relationship between shipping experience and customer reviews.

The analysis was performed using multiple data analysis and visualization tools to generate meaningful business insights and support data-driven decision-making.

🎯 Business Objectives
The main objectives of this project were to:

- Analyze payment patterns across weekdays and weekends.
- Identify orders with a review score of 5 and credit card payments.
- Analyze average delivery time for the pet shop category.
- Analyze average product price and payment values by city.
- Understand the relationship between shipping days and customer review scores.
- Build interactive dashboards to present the findings clearly.

  

🛠️ Tools & Technologies

- Microsoft Excel – Data analysis, Pivot Tables, calculations, and dashboard creation
- MySQL – SQL queries and data analysis
- Power BI – Interactive dashboard and data visualization
- Tableau – Interactive dashboard and data visualization

  

📊 Key Analysis

1. Weekday vs Weekend Payment Statistics
Compared payment activity between weekdays and weekends to identify differences in customer payment behavior.


2. Review Score 5 & Credit Card Orders
Analyzed orders that received a perfect review score of 5 and were paid using credit cards.


3. Average Delivery Days – Pet Shop
Calculated the average number of days taken to deliver orders belonging to the pet shop category.


4. Average Price & Payment Value by City
Analyzed average product prices and payment values for different cities to identify differences in purchasing behavior.


5. Shipping Days vs Review Score
Analyzed whether delivery/shipping time has a relationship with customer satisfaction and review scores.
