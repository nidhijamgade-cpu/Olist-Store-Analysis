# Olist-Store-Analysis
About the Project

An e-commerce data analysis project using the Olist dataset to understand customer behavior, payments, delivery performance, and customer satisfaction.

🛠️ Tools Used

- Excel
- MySQL / SQL
- Power BI
- Tableau

📊 Analysis Performed

- Weekday vs Weekend Payment Analysis
- Review Score & Payment Analysis
- Average Delivery Time for Pet Shop
- Average Price & Payment Value by City
- Shipping Days vs Review Score
